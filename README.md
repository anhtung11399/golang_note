# Go cho dân Frontend

Lộ trình học backend Golang cho lập trình viên frontend: 25 bài, sơ đồ, code mẫu, bài tập.

- Nội dung bài: `src/lessons/*.html`, danh sách và thứ tự bài: `src/lessons.mjs`
- Trang chủ và trang tra cứu: `src/pages/`, CSS / JS: `src/static/`
- Dựng trang: `node build.mjs` (sinh `index.html` và các trang ra gốc repo cho GitHub Pages)
