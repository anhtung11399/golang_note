Cài đặt

Tải bản cài từ go.dev/dl (có bản cho macOS, Windows, Linux), hoặc trên macOS dùng Homebrew:

brew install go
go version        # in ra phiên bản, ví dụ: go version go1.2x darwin/arm64

Lộ trình này dùng các tính năng có từ Go 1.22 trở lên (định tuyến mới của net/http, vòng lặp for i := range 10). Cài bản mới nhất là đủ.

Trình soạn thảo: VS Code + tiện ích Go (của nhóm Go tại Google). Nó cài gopls (giống TypeScript language server), tự định dạng và tự thêm import khi lưu file. GoLand của JetBrains cũng rất tốt nếu bạn quen WebStorm.

Chưa muốn cài? Mở go.dev/play và dán code của các bài 02 đến 07 vào chạy thử. Từ bài 08 trở đi bạn sẽ cần máy thật.

Chương trình đầu tiên

Mở terminal và làm đúng ba bước sau.

Bước 1. Tạo thư mục dự án và file go.mod:

mkdir hello        # tạo thư mục tên hello
cd hello           # đi vào thư mục đó. Mọi lệnh go bên dưới đều chạy TRONG thư mục này
go mod init example.com/hello   # tạo file go.mod, giống npm init tạo package.json

Bước 2. Trong thư mục hello, tạo file main.go và dán nội dung sau:

package main

import (
    "fmt"
    "os"
)

func main() {
    name := "bạn"
    if len(os.Args) > 1 {
        name = os.Args[1]
    }
    fmt.Printf("Xin chào, %s!\n", name)
}

Bước 3. Chạy:

go run .

Xin chào, bạn!

Dấu chấm trong go run . nghĩa là "chạy package ở thư mục hiện tại". Bạn phải đang đứng trong thư mục hello thì lệnh mới tìm thấy main.go.

os.Args: chữ bạn gõ sau lệnh chạy

Khi bạn gõ go run . Lan 3, Go đưa vào chương trình một danh sách chuỗi:

[ext] os.Args[0] / "/tmp/go-build.../hello" [go] os.Args[1] / "Lan" [go] os.Args[2] / "3" (chuỗi, chưa phải số)

Vì vậy cùng một chương trình, gõ khác nhau thì in khác nhau:

$ go run .
Xin chào, bạn!
$ go run . Tùng
Xin chào, Tùng!

Dòng có dấu $ ở đầu là lệnh bạn gõ (không gõ dấu $), dòng bên dưới là chương trình in ra.

Go Playground không truyền được tham số. Trên go.dev/play không có chỗ gõ Lan 3, nên os.Args chỉ có phần tử 0. Chương trình nào đọc os.Args phải chạy bằng terminal trên máy.

Tạo file chạy

go build -o hello .   # biên dịch ra file tên hello trong thư mục hiện tại
./hello Lan           # chạy file đó, không cần lệnh go nữa

Xin chào, Lan!

Code Go được chạy như thế nào

JavaScript được trình duyệt hoặc Node đọc và chạy (có JIT). Go thì khác: trình biên dịch dịch toàn bộ code thành mã máy cho một hệ điều hành và loại CPU cụ thể, đóng gói luôn thư viện và runtime (bộ lập lịch goroutine, bộ thu gom rác) vào một file duy nhất.

[go] main.go + package khác / mã nguồn của bạn -> go build [go] Trình biên dịch / kiểm tra kiểu, tối ưu -> liên kết [ok] Một file chạy / mã máy + runtime Go -> copy lên server [ext] Máy chủ Linux / chạy ngay: ./app

Bạn còn có thể biên dịch cho hệ điều hành khác ngay trên máy Mac:

GOOS=linux GOARCH=amd64 go build -o app-linux .   # file chạy cho máy chủ Linux x86
GOOS=windows GOARCH=amd64 go build -o app.exe .

Đây là một lý do các công cụ như Docker, kubectl, Terraform, Hugo được viết bằng Go: người dùng chỉ cần tải một file về là chạy, không cần cài runtime.

Trình biên dịch nghiêm khắc

Go từ chối biên dịch nếu có biến cục bộ không dùng hoặc import không dùng. Lúc đầu thấy khó chịu, nhưng nhờ vậy code Go hiếm khi có rác.

package main

import (
    "fmt"
    "os" // lỗi: "os" imported and not used
)

func main() {
    x := 5 // lỗi: declared and not used: x
    fmt.Println("hi")
}

Tiện ích Go của VS Code tự thêm và xoá import khi bạn lưu file, nên thực tế bạn ít khi phải tự sửa lỗi import.

Giống bật noUnusedLocals trong tsconfig, nhưng không tắt được (tham số hàm không dùng thì Go vẫn cho phép). Muốn bỏ qua một giá trị, gán cho dấu gạch dưới: _ = x.

Đọc tài liệu và mã nguồn

Mọi package công khai đều có tài liệu trên pkg.go.dev, sinh tự động từ chú thích trong code. Ngay trong terminal:

go doc fmt.Printf           # xem tài liệu của một hàm
go doc net/http.Server      # xem một kiểu

Trong VS Code, giữ Cmd và bấm vào tên hàm để nhảy vào mã nguồn của chính thư viện chuẩn. Code thư viện chuẩn Go rất dễ đọc: đây là cách học nhanh nhất.

- Vì máy chủ chưa cài Go + Vì file được biên dịch cho macOS. Cần build lại với GOOS=linux (và GOARCH đúng loại CPU của máy chủ) - Vì thiếu thư mục node_modules ? File chạy của Go là mã máy cho một hệ điều hành và CPU cụ thể. Máy chủ không cần cài Go, nhưng file phải được build đúng nền tảng.

Bài tập

Lời chào có tham số

Sửa chương trình để nhận hai tham số: tên và số lần chào. Khi gõ lệnh dưới đây trong terminal, chương trình in 3 dòng:

$ go run . Lan 3
Xin chào, Lan!
Xin chào, Lan!
Xin chào, Lan!

Nếu người dùng gõ thiếu tham số hoặc số lần không phải số, in ra hướng dẫn thay vì bị lỗi.

Gợi ý từng bước

  1. Theo hình os.Args ở trên: tên nằm ở os.Args[1], số lần nằm ở os.Args[2]. Muốn có cả hai thì len(os.Args) phải ít nhất là 3.
  2. os.Args[2] là chuỗi "3", chưa dùng để đếm được. Đổi sang số bằng strconv.Atoi("3"). Hàm này trả về hai giá trị: con số, và một lỗi (nil nếu không có lỗi). Giống Number("3") của JS, nhưng thay vì ra NaN thì Go báo lỗi.
  3. Lặp n lần bằng for i := 0; i < n; i++ { ... }, giống vòng for của JS nhưng không có ngoặc tròn.
Xem lời giải 
package main

import (
    "fmt"
    "os"
    "strconv" // đổi chuỗi sang số
)

func main() {
    // Cần tên chương trình + 2 chữ người dùng gõ = 3 phần tử
    if len(os.Args) < 3 {
        fmt.Println("Cách dùng: go run .  ")
        fmt.Println("Ví dụ:     go run . Lan 3")
        os.Exit(1) // dừng chương trình, mã 1 nghĩa là có lỗi
    }

    name := os.Args[1] // "Lan"

    // Atoi trả về 2 giá trị: số và lỗi
    n, err := strconv.Atoi(os.Args[2]) // "3" -> 3
    if err != nil || n < 1 {
        // err khác nil: chuỗi không phải số, ví dụ "ba"
        fmt.Println("Số lần phải là số nguyên dương, ví dụ 3")
        os.Exit(1)
    }

    // i chạy 0, 1, 2: lặp đúng n = 3 lần
    for i := 0; i < n; i++ {
        fmt.Printf("Xin chào, %s!\n", name)
    }
}

$ go run . Lan 3
Xin chào, Lan!
Xin chào, Lan!
Xin chào, Lan!

Chạy thử các trường hợp sai, để thấy chương trình tự bảo vệ:

$ go run .
Cách dùng: go run .  
Ví dụ:     go run . Lan 3
exit status 1
$ go run . Lan ba
Số lần phải là số nguyên dương, ví dụ 3
exit status 1

Nếu bạn chỉ bấm Run (trên Go Playground hoặc nút Run của VS Code) hay gõ go run . mà không có Lan 3, chương trình sẽ in "Cách dùng" chứ không in 3 lần. Đó là đúng: không có tham số thì nó không biết chào ai. Dòng exit status 1 là lệnh go run báo chương trình đã dừng bằng os.Exit(1).

Giải thích

  • n, err := strconv.Atoi(...): một hàm Go trả về nhiều giá trị cùng lúc, gán vào nhiều biến bằng dấu phẩy. Giống destructuring const [n, err] = atoi(...) trong JS.
  • if err != nil: nil giống null. Lỗi khác nil nghĩa là có lỗi. Bạn sẽ gặp hai dòng này ở khắp mọi nơi trong code Go (bài 07 nói kỹ).
  • os.Exit(1): kết thúc chương trình ngay. Số 0 là thành công, khác 0 là lỗi. Các công cụ như CI dựa vào số này để biết lệnh chạy được hay không.

Muốn thử trên Go Playground (không có tham số): thay hai dòng đọc os.Args bằng giá trị gõ sẵn:

package main

import "fmt"

func main() {
    name := "Lan" // thay cho os.Args[1]
    n := 3        // thay cho os.Args[2] đã đổi sang số

    for i := 0; i < n; i++ {
        fmt.Printf("Xin chào, %s!\n", name)
    }
}

Build cho ba hệ điều hành

Build chương trình trên ra ba file cho macOS, Linux và Windows. So sánh kích thước với thư mục node_modules của một dự án React bất kỳ.

Xem lời giải 
GOOS=darwin  GOARCH=arm64 go build -o dist/hello-mac .
GOOS=linux   GOARCH=amd64 go build -o dist/hello-linux .
GOOS=windows GOARCH=amd64 go build -o dist/hello.exe .
ls -lh dist

Mỗi file chỉ vài MB và chạy độc lập. Thêm -ldflags="-s -w" để bỏ thông tin gỡ lỗi, file còn nhỏ hơn.
