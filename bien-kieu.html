Biến, kiểu dữ liệu và zero value

Kiểu tĩnh, khai báo biến, hằng, chuyển kiểu, string và rune, đối chiếu từng thứ với TypeScript.

Học xong bài này bạn sẽ:
  • Khai báo biến bằng var và :=
  • Hiểu zero value thay cho undefined / null
  • Xử lý chuỗi tiếng Việt đúng cách (byte và rune)

#Khai báo biến

Go có hai cách khai báo biến. Cách ngắn := dùng nhiều nhất, nhưng chỉ dùng được bên trong hàm.

Go
package main

import "fmt"

var appName = "Sổ bài tập" // ngoài hàm: phải dùng var

func main() {
    var age int = 30      // đầy đủ: var tên kiểu = giá trị
    var city = "Hà Nội"   // bỏ kiểu, Go tự suy ra string
    var score float64     // không gán: nhận zero value là 0
    count := 10           // cách ngắn, hay dùng nhất trong hàm
    a, b := 1, "hai"      // khai báo nhiều biến một lúc

    count = 11            // gán lại: dùng =, không dùng :=
    fmt.Println(appName, age, city, score, count, a, b)
}
Terminal — kết quả khi chạy
Sổ bài tập 30 Hà Nội 0 11 1 hai

Đọc chương trình trên:

  • var age int = 30: đọc là "tạo biến age, kiểu int (số nguyên), giá trị 30". Trong Go, kiểu viết sau tên biến, ngược với Java / C. TypeScript cũng viết sau: let age: number = 30.
  • var score float64 không gán giá trị, nên score tự có giá trị 0 (xem "Zero value" bên dưới). In ra thấy số 0.
  • count := 10: cách viết ngắn của var count = 10. Dấu := = "tạo mới và gán". Dấu = = "gán lại cho biến đã có".
  • fmt.Println(...) in tất cả giá trị trên một dòng, cách nhau bởi dấu cách, rồi xuống dòng. Giống console.log(a, b, c).
TypeScriptGo
let x = 5x := 5
let x: numbervar x int (có giá trị 0, không phải undefined)
const PI = 3.14const Pi = 3.14
x = 6x = 6

:= luôn tạo biến mới. Trong một khối lệnh con (if, for), x := ... sẽ tạo ra biến x mới che mất biến x bên ngoài (shadowing). Đây là lỗi hay gặp với err: bạn tưởng đã gán lỗi cho biến bên ngoài nhưng thật ra gán cho một biến khác. go vet với công cụ shadow có thể phát hiện giúp bạn.

Không bao giờ dùng float cho tiền

Số thực (float64) được lưu dạng nhị phân nên không biểu diễn chính xác được nhiều số thập phân, giống hệt JavaScript:

Go
package main

import "fmt"

func main() {
    a := 0.1
    b := 0.2
    fmt.Println(a + b) // mong 0.3 nhưng không phải
}
Terminal — kết quả khi chạy

Cộng lệch một chút thì với tiền là sai: cộng dồn hàng nghìn đơn hàng sẽ lệch cả đồng. Ngoài thực tế, tiền được lưu bằng số nguyên ở đơn vị nhỏ nhất: đồng với VND, cent với USD. Stripe API nhận amount: 1999 nghĩa là 19,99 USD. Trong database dùng bigint hoặc numeric.

GoĐúng / nên làm
package main

import "fmt"

// Tạo kiểu mới tên VND, bên trong là số nguyên 64 bit
type VND int64

func main() {
    price := VND(49_000) // dấu _ chỉ để dễ đọc, Go bỏ qua nó: 49_000 = 49000
    total := price * 3   // số nguyên nhân số nguyên: luôn chính xác
    fmt.Println(total)
}
Terminal — kết quả khi chạy

VND(49_000) là đổi kiểu: biến số 49000 thành giá trị kiểu VND. Phần "Kiểu tự định nghĩa" cuối bài giải thích vì sao nên tạo kiểu riêng như vậy.

#Zero value: không có undefined

Trong Go, biến khai báo mà chưa gán luôn có giá trị mặc định gọi là zero value. Không có undefined, không có biến "chưa khởi tạo".

KiểuZero value
số (int, float64…)0
string"" (chuỗi rỗng)
boolfalse
con trỏ, slice, map, channel, hàm, interfacenil
structstruct với mọi trường là zero value

Nhà thiết kế Go cố tình làm cho zero value hữu dụng: một sync.Mutex hay bytes.Buffer mới khai báo là dùng được ngay, không cần gọi hàm khởi tạo.

Zero value gây ra một câu hỏi rất thật ở backend: client gửi {"score": 0} hay không gửi score? Với int, cả hai đều thành 0. Khi cần phân biệt "không có" và "bằng 0" (ví dụ API cập nhật một phần, PATCH), người ta dùng con trỏ *int (nil = không gửi). Bài 5 và 13 sẽ dùng cách này.

Tự kiểm chứng:

Go
package main

import "fmt"

func main() {
    var n int
    var s string
    var ok bool
    var list []int // slice (giống mảng), bài 04

    fmt.Println(n, ok)            // số 0 và false
    fmt.Printf("%q\n", s)         // %q in chuỗi kèm dấu nháy, để thấy chuỗi rỗng
    fmt.Println(list == nil)      // slice chưa tạo là nil
}
Terminal — kết quả khi chạy
0 false

#Hằng số và iota

const giống const của JS nhưng chặt hơn: giá trị phải biết được ngay lúc biên dịch (số, chuỗi, bool). Không thể const now = time.Now().

Go
package main

import "fmt"

const MaxUploadMB = 5

const (
    PageSize    = 20
    MaxPageSize = 100
)

// Role là kiểu mới, bên trong là int
type Role int

// iota: bộ đếm tự tăng trong một khối const, bắt đầu từ 0
const (
    RoleStudent Role = iota // iota = 0
    RoleParent              // không viết gì: Go lặp lại "Role = iota", lúc này iota = 1
    RoleTeacher             // iota = 2
)

func main() {
    fmt.Println(MaxUploadMB, PageSize, MaxPageSize)
    fmt.Println(RoleStudent, RoleParent, RoleTeacher)
}
Terminal — kết quả khi chạy
5 20 100
0 1 2

Go không có từ khoá enum. Với giá trị sẽ lưu vào database hoặc gửi qua JSON, nhiều đội thích dùng kiểu chuỗi hơn vì đọc log và dữ liệu dễ hiểu, và không bị lệch khi ai đó chèn thêm hằng vào giữa khối iota:

Go · trích đoạn
type Status string

const (
    StatusPending Status = "pending"
    StatusPaid    Status = "paid"
)

#Chuyển kiểu: luôn phải viết rõ

JavaScript tự đổi kiểu ("5" * 2 ra 10). Go thì không bao giờ tự đổi, kể cả giữa hai loại số int và int64. Muốn đổi, viết KiểuMới(giá_trị), nhìn giống gọi hàm.

Go
package main

import "fmt"

func main() {
    var a int = 10
    var b int64 = 20

    // c := a + b       // bỏ dấu // ở đầu dòng này sẽ lỗi: mismatched types int and int64
    c := int64(a) + b   // đổi a sang int64 rồi mới cộng
    fmt.Println(c)

    f := float64(a) / 3 // đổi sang số thực thì phép chia mới có phần thập phân
    fmt.Println(f)

    fmt.Println(a / 3)  // int chia int: bỏ phần dư, giống Math.trunc(10 / 3)

    x := 3.99
    fmt.Println(int(x)) // cắt phần thập phân, KHÔNG làm tròn
}
Terminal — kết quả khi chạy
30
3.3333333333333335
3
3

Chuỗi và số đổi qua lại bằng package strconv (viết tắt của string convert). Đổi chuỗi sang số có thể thất bại (chuỗi "abc" đâu phải số), nên hàm trả về thêm một giá trị lỗi:

Go
package main

import (
    "fmt"
    "strconv"
)

func main() {
    n, err := strconv.Atoi("42") // Atoi = "ASCII to int": chuỗi -> số
    fmt.Println(n, err)          // err là nil: không có lỗi

    n, err = strconv.Atoi("abc") // dùng = vì n, err đã tạo ở trên
    fmt.Println(n, err)          // n = 0, err mô tả lỗi

    s := strconv.Itoa(42)        // Itoa = "int to ASCII": số -> chuỗi
    fmt.Printf("%q\n", s)

    id, err := strconv.ParseInt("9001", 10, 64) // cơ số 10, kết quả int64
    fmt.Println(id, err)
}
Terminal — kết quả khi chạy
42 <nil>
0 strconv.Atoi: parsing "abc": invalid syntax
"42"
9001 <nil>

Dòng cuối dùng lại := dù err đã có: được phép vì bên trái có ít nhất một biến mới (id). Go tạo id mới và gán lại cho err cũ.

string(65) cho ra "A" (ký tự mã 65), không phải "65". go vet sẽ cảnh báo chỗ này. Muốn đổi số thành chuỗi số, luôn dùng strconv.Itoa hoặc fmt.Sprint.

#Chuỗi tiếng Việt: byte và rune

Đây là chỗ dân Việt hay vấp. Chuỗi Go là một dãy byte mã hoá UTF-8. Chữ có dấu chiếm nhiều byte.

Go
package main

import (
    "fmt"
    "unicode/utf8"
)

func main() {
    s := "Việt"
    fmt.Println(len(s))                    // len đếm BYTE
    fmt.Println(utf8.RuneCountInString(s)) // đếm KÝ TỰ
    fmt.Println(s[1])                      // s[1] là byte thứ 2, in ra dạng số

    // range trên chuỗi đi theo từng ký tự (rune):
    // i = vị trí byte bắt đầu của ký tự, r = chính ký tự đó
    for i, r := range s {
        fmt.Printf("%d:%c ", i, r) // %d in số, %c in ký tự
    }
    fmt.Println()
}
Terminal — kết quả khi chạy
6
4
105
0:V 1:i 2:ệ 5:t

Để ý vị trí nhảy từ 2 lên 5: chữ ệ chiếm 3 byte (vị trí 2, 3, 4). 105 là mã của chữ i trong bảng mã. Trong JS, "Việt".length là 4 vì JS đếm theo đơn vị UTF-16, nên dân frontend hay bất ngờ ở đây.

Hậu quả: cắt chuỗi bằng s[:3] (lấy 3 byte đầu) có thể cắt đôi chữ có dấu. Cách đúng là đổi chuỗi thành danh sách ký tự []rune rồi mới cắt:

Go
package main

import "fmt"

// truncate cắt chuỗi còn tối đa max KÝ TỰ, thêm "…" nếu bị cắt
func truncate(s string, max int) string {
    r := []rune(s)    // "Việt Nam" -> [V i ệ t _ N a m], mỗi phần tử một ký tự
    if len(r) <= max { // ngắn sẵn thì trả nguyên
        return s
    }
    return string(r[:max]) + "…" // r[:max] = max phần tử đầu, string(...) ghép lại thành chuỗi
}

func main() {
    s := "Việt Nam"
    fmt.Printf("%q\n", s[:3])      // SAI: cắt 3 byte, đứt đôi chữ ệ
    fmt.Println(truncate(s, 3))    // ĐÚNG: 3 ký tự
    fmt.Println(truncate(s, 20))   // chuỗi ngắn hơn 20 thì giữ nguyên
}
Terminal — kết quả khi chạy
"Vi\xe1"
Việ…
Việt Nam

"Vi\xe1": \xe1 là byte đầu tiên của chữ ệ bị bỏ lại một mình, không thành chữ nào cả. Lên giao diện sẽ hiện dấu �.

Khi API nói "tên tối đa 80 ký tự", hãy đếm bằng utf8.RuneCountInString. Nếu đếm bằng len, người dùng gõ tên tiếng Việt có dấu sẽ bị báo quá dài sớm hơn người gõ không dấu. Còn khi giới hạn dung lượng lưu trữ (cột database tính theo byte), thì mới dùng len.

Làm việc với chuỗi

Các hàm xử lý chuỗi nằm trong package strings. Khác JS: JS gọi method trên chuỗi ("abc".toLowerCase()), Go gọi hàm và truyền chuỗi vào (strings.ToLower("abc")).

Go
package main

import (
    "fmt"
    "strings"
)

func main() {
    fmt.Println(strings.ToLower("Email@Gmail.COM"))       // .toLowerCase()
    fmt.Printf("%q\n", strings.TrimSpace("  lan  "))      // .trim()
    fmt.Println(strings.Contains("hotoedu", "edu"))       // .includes()
    fmt.Println(strings.Split("a,b,c", ","))              // .split(","): ra slice 3 phần tử
    fmt.Println(strings.Join([]string{"a", "b"}, "-"))    // [a, b].join("-")
    fmt.Println(strings.HasPrefix("/api/users", "/api/")) // .startsWith()

    // Ghép nhiều chuỗi trong vòng lặp: dùng strings.Builder, không dùng +=
    var sb strings.Builder
    for i := 0; i < 3; i++ {
        fmt.Fprintf(&sb, "dòng %d\n", i) // ghi vào sb thay vì in ra màn hình
    }
    fmt.Print(sb.String()) // lấy toàn bộ chuỗi đã ghép
}

Chuỗi trong Go không đổi được, nên s += "x" trong vòng lặp lớn sẽ tạo chuỗi mới mỗi lần. strings.Builder tránh việc đó.

#In và định dạng với fmt

fmt.Printf nhận một chuỗi mẫu có các "chỗ trống" bắt đầu bằng %, rồi lần lượt điền các giá trị phía sau vào. Các chỗ trống hay dùng:

Ký hiệuIn ra
%vGiá trị, kiểu nào cũng được (v = value). Không biết dùng gì thì dùng cái này.
%+vNhư %v, kèm tên trường của struct. Hay dùng khi gỡ lỗi.
%d / %sSố nguyên / chuỗi
%.2fSố thực, lấy 2 chữ số sau dấu chấm
%qChuỗi kèm dấu nháy, thấy rõ khoảng trắng thừa
%TTên kiểu của giá trị
Go
package main

import "fmt"

// struct: gom nhiều trường thành một kiểu, giống interface của TS (bài 05)
type User struct {
    ID   int64
    Name string
}

func main() {
    u := User{ID: 1, Name: "Lan"}

    fmt.Printf("%v\n", u)
    fmt.Printf("%+v\n", u)
    fmt.Printf("%T\n", u)
    fmt.Printf("%q\n", " a ")
    fmt.Printf("%d %.2f %s\n", 7, 3.14159, "x") // 3 chỗ trống, 3 giá trị theo thứ tự

    msg := fmt.Sprintf("Đơn #%d", 9001) // Sprintf: tạo chuỗi, KHÔNG in
    fmt.Println(msg)
}
Terminal — kết quả khi chạy
{1 Lan}
{ID:1 Name:Lan}
main.User
" a "
7 3.14 x
Đơn #9001

Ba hàm in cần nhớ: Println (in các giá trị, tự xuống dòng), Printf (in theo mẫu, phải tự thêm \n), Sprintf (giống Printf nhưng trả về chuỗi thay vì in).

#Kiểu tự định nghĩa

Bạn có thể tạo kiểu mới từ kiểu có sẵn. Go coi chúng là khác nhau, nên trình biên dịch giúp bạn không truyền nhầm.

Go
package main

import "fmt"

type UserID int64  // bên trong đều là int64...
type ClassID int64 // ...nhưng Go coi là hai kiểu khác nhau

func GetUser(id UserID) {
    fmt.Println("lấy người dùng", id)
}

func main() {
    var c ClassID = 5
    // GetUser(c)      // bỏ // sẽ lỗi: cannot use c (variable of type ClassID) as UserID value
    GetUser(UserID(7)) // đúng: giá trị đúng kiểu UserID
    _ = c              // dấu _ : "biết là có biến c, cố ý không dùng" để Go không báo lỗi
}
Terminal — kết quả khi chạy
lấy người dùng 7

Lợi ích thật: hàm MoveStudent(studentID, classID) mà truyền ngược hai tham số là lỗi ngay lúc biên dịch, không phải đợi lên production mới phát hiện.

TypeScript dùng kiểu cấu trúc (structural), nên type UserId = number và type ClassId = number là một. Người ta phải dùng mẹo "branded types". Trong Go, kiểu đặt tên là khác nhau thật sự.

Câu hỏi nhanh. len("Học") trả về bao nhiêu?

len đếm byte. "H" và "c" mỗi chữ 1 byte, "ọ" (U+1ECD) chiếm 3 byte trong UTF-8. Tổng là 5 byte, dù chỉ có 3 ký tự.

Câu hỏi nhanh. Một API nhận {"quantity": 0} và một API khác không gửi quantity. Với struct có trường Quantity int, sau khi đọc JSON, giá trị là gì?

int không thể là nil. Trường không có trong JSON giữ zero value. Muốn phân biệt, dùng *int (nil nghĩa là không gửi) hoặc kiểm tra bắt buộc khi validate.

Chuẩn hoá email và kiểm tra độ dài tên

Viết hai hàm:

  • normalizeEmail(s string) string: nhận email người dùng gõ, bỏ khoảng trắng hai đầu và đổi về chữ thường.
  • validName(s string) bool: trả true nếu tên (sau khi bỏ khoảng trắng hai đầu) có từ 2 đến 80 ký tự.

Kết quả mong muốn khi chạy:

Terminal — kết quả khi chạy
lan.nguyen@gmail.com
true
false

Gợi ý từng bước

  1. Cách viết hàm trong Go: func tênHàm(thamSố kiểu) kiểuTrảVề { ... }. Ví dụ func normalizeEmail(s string) string = hàm nhận một chuỗi s, trả về một chuỗi. Giống function normalizeEmail(s: string): string trong TS.
  2. Bỏ khoảng trắng: strings.TrimSpace(s). Chữ thường: strings.ToLower(s). Có thể lồng: kết quả của hàm này làm đầu vào của hàm kia.
  3. Đếm ký tự (không phải byte, vì tên tiếng Việt có dấu): utf8.RuneCountInString(s).
  4. Trong main, gọi hai hàm với dữ liệu thử và in kết quả.
Xem lời giải
main.go
package main

import (
    "fmt"
    "strings"
    "unicode/utf8"
)

func normalizeEmail(s string) string {
    // Chạy từ trong ra ngoài: TrimSpace trước, kết quả đưa vào ToLower
    return strings.ToLower(strings.TrimSpace(s))
}

func validName(s string) bool {
    n := utf8.RuneCountInString(strings.TrimSpace(s)) // số ký tự sau khi bỏ khoảng trắng
    return n >= 2 && n <= 80                          // biểu thức so sánh cho ra true / false
}

func main() {
    fmt.Println(normalizeEmail("  Lan.Nguyen@Gmail.COM ")) // lan.nguyen@gmail.com
    fmt.Println(validName("  Nguyễn Thị Ánh  "))           // true
    fmt.Println(validName("A"))                            // false
}
Terminal — kết quả khi chạy
lan.nguyen@gmail.com
true
false

Cách chạy: tạo thư mục mới, go mod init bai02, dán code vào main.go, gõ go run .. Hoặc dán vào go.dev/play và bấm Run (bài này không cần tham số).

Giải thích: " Nguyễn Thị Ánh " sau khi bỏ khoảng trắng còn 14 ký tự (nhưng tới 19 byte), nằm trong khoảng 2 đến 80 nên ra true. "A" chỉ có 1 ký tự nên false.

Ngoài thực tế, email luôn được chuẩn hoá về chữ thường trước khi lưu và trước khi tìm, nếu không Lan@gmail.com và lan@gmail.com sẽ thành hai tài khoản.

Định dạng tiền Việt

Viết hàm formatVND(v int64) string đổi số thành chuỗi tiền có dấu chấm ngăn cách hàng nghìn. Số âm có dấu trừ phía trước. Kết quả mong muốn:

Terminal — kết quả khi chạy
1.234.567đ
49.000đ
500đ
-1.500.000đ

Gợi ý từng bước

  1. Nếu số âm: nhớ lại điều đó, rồi đổi thành số dương để xử lý cho dễ.
  2. Đổi số thành chuỗi chữ số: strconv.FormatInt(v, 10) cho "1234567".
  3. Đi qua từng chữ số từ trái sang phải. Trước chữ số nào mà số chữ số còn lại tính từ nó đến cuối chia hết cho 3 thì chèn dấu chấm. Với "1234567" (7 chữ số): trước chữ 2 còn 6 chữ số, trước chữ 5 còn 3 chữ số, nên chèn ở hai chỗ đó.
  4. Ghép dần vào strings.Builder, cuối cùng thêm "đ" (và "-" nếu âm).
Xem lời giải
main.go
package main

import (
    "fmt"
    "strconv"
    "strings"
)

func formatVND(v int64) string {
    neg := v < 0 // nhớ lại là số âm hay không
    if neg {
        v = -v // đổi sang số dương
    }

    s := strconv.FormatInt(v, 10) // 1234567 -> "1234567"

    var sb strings.Builder
    for i, ch := range s { // i = vị trí (0, 1, 2...), ch = chữ số ở vị trí đó
        remaining := len(s) - i // số chữ số từ vị trí i tới cuối
        if i > 0 && remaining%3 == 0 { // % là phép chia lấy dư
            sb.WriteByte('.')
        }
        sb.WriteRune(ch)
    }

    if neg {
        return "-" + sb.String() + "đ"
    }
    return sb.String() + "đ"
}

func main() {
    fmt.Println(formatVND(1234567))
    fmt.Println(formatVND(49000))
    fmt.Println(formatVND(500))
    fmt.Println(formatVND(-1500000))
}

49.000đ
500đ
