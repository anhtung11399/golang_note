Lộ trình viết riêng cho người đã quen React / Angular / TypeScript nhưng chưa từng làm backend. Mỗi bài đối chiếu với thứ bạn đã biết ở frontend, có sơ đồ, code chạy được, ví dụ từ hệ thống thật và bài tập.

#Cách học để thật sự làm được

Gõ lại, đừng chép

Mỗi đoạn code hãy tự gõ và chạy. Sai chính tả, quên import, trình biên dịch báo lỗi: đó chính là lúc bạn học.

Làm bài tập trước khi xem lời giải

Bí 15 phút mới mở lời giải. Mở rồi thì đóng lại và tự viết lại từ đầu.

Mỗi chặng một dự án nhỏ

Hết chặng 2 bạn có API chạy được, hết chặng 3 có database, hết chặng 4 có đăng nhập. Chặng 6 ghép thành sản phẩm hoàn chỉnh.

Dùng chỗ mạnh của dân FE

Bạn đã hiểu HTTP, JSON, async, state, component. Backend chỉ là nhìn những thứ đó từ phía bên kia.

Đọc code thật

Thư viện chuẩn của Go viết rất dễ đọc. Khi thắc mắc một hàm chạy ra sao, mở mã nguồn trên pkg.go.dev.

#Tài liệu chính thức nên đánh dấu

  • A Tour of Go: chạy thử Go ngay trên trình duyệt.
  • Go Playground: dán code trong bài vào để chạy, không cần cài đặt.
  • Effective Go và Go Code Review Comments: phong cách viết Go chuẩn.
  • pkg.go.dev/std: tài liệu thư viện chuẩn.
  • Go by Example: tra cứu nhanh theo ví dụ.
  • Uber Go Style Guide: quy tắc viết Go của một công ty có hàng nghìn dịch vụ Go.
